# Integrated Donation Manager

A web-based platform for managing financial donations, NGO operations, and transparent fund tracking.


## Overview

The Integrated Donation Manager is a web application that helps NGOs manage donations, track expenses, and generate reports. It replaces manual paperwork with an automated system that saves time and builds donor trust.


## Features

### Donor Module
- Secure registration and login
- One-time and recurring donations
- Donation history tracking
- Automated 80G tax receipt generation

### NGO Module
- Manage donation entries
- Track expenditures
- Create budget reports
- Digital cashbook maintenance

### Admin Module
- Verify NGO applications
- Approve or reject budgets
- Monitor transactions
- Generate system reports


## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Python (Flask)
- **Database:** MySQL
- **Payment Gateway:** Razorpay API


## Installation

### Prerequisites
- Python 3.8 or higher
- pip

### Steps

Clone the repository:

git clone https://github.com/sam-1510-hash/Integrated-Donation-Manager.git
cd Integrated-Donation-Manager

Create virtual environment:

python -m venv venv
venv\Scripts\activate  # Windows
source venv/bin/activate  # Mac/Linux

Install dependencies:

pip install -r requirements.txt

Run the application:

python app.py
Access: http://localhost:5000
